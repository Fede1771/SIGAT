# Versiones anteriores

Estos archivos se conservan como referencia. Para instalar en una PC nueva usar `../01_Instalacion_Completa.sql`; para actualizar una base existente usar `../02_Actualizar_Base_Existente.sql`.

No ejecutar todos los archivos de esta carpeta. El instalador anterior quedó incompleto respecto del código actual; los scripts de roles representan etapas reunidas en los archivos actuales. Los T05 corresponden a otro esquema de idiomas y pueden borrar tablas o producir errores sobre la base actual.
